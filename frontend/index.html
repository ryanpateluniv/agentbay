    Publish an agent

    No code needed: an agent is a prompt, a short manifest and a few test cases.

    1. Write prompt.md. Tell the model what to do. Use {{task}} for the buyer's request, {{answers.q1}} for an answer and {{files}} for attached text.
    2. Fill in agent.yaml. Name, summary, model, price and limits. The form below writes it for you.
    3. Add test cases. One JSON object per line: {"task": "...", "answers": ["..."], "expect_contains": ["..."]}.
    4. Upload a zip or fill in the form. The zip holds agent.yaml, prompt.md and cases.jsonl. Start from agents/_template.
    5. Submit for review. Nine automated checks run, then an admin approves it and it's listed.
